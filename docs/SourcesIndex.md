# Sources Index

This index tracks all source documents, their origins, verification status, and accessibility.

## Source Verification Levels

- ✅ **Level 1: Official Court Documents** - Filed with and released by courts
- ✅ **Level 2: Government Records** - Released by government agencies via FOIA or official channels
- ⚠️ **Level 3: Verified Media** - Obtained and verified by credible news organizations
- ⚠️ **Level 4: Secondary Sources** - Referenced in verified documents
- ❌ **Level 5: Unverified** - Awaiting verification

## Source Citation Format

When citing documents, use the following format:

```
[Document Type] - [Case/Source] - [Date] - [Document ID]
Example: Court Filing - SDNY-19-cr-00490 - 2019-07-08 - Exhibit A
```

## Document Request Process

### Obtaining Official Documents

1. **Court Records**
   - Access via PACER (Public Access to Court Electronic Records)
   - Request from court clerk
   - Check for public release programs

2. **Government Records**
   - File FOIA requests
   - Check agency websites for released documents
   - Monitor official release schedules

3. **Public Records**
   - County clerk offices
   - State agencies
   - Property records databases

## Verification Checklist

Before adding a document to the index:

- [ ] Source identified and documented
- [ ] Document authenticity verified
- [ ] Date and context confirmed
- [ ] Metadata recorded
- [ ] Cross-referenced with other sources
- [ ] Privacy considerations reviewed
- [ ] Legal restrictions checked
