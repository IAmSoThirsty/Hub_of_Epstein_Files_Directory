QUICK START
-----------

1. Run automated setup:
   ./setup.sh

2. Verify installation:
   python verify-setup.py

3. View available commands:
   make help

4. Start using the tools:
   make fetch-public-files
   make generate-index
   make serve

MAKEFILE COMMANDS
-----------------

Setup & Installation:
  make setup              - Run initial setup
  make install            - Install dependencies
  make verify             - Verify installation

Data Processing:
  make fetch-public-files - Fetch FBI Vault PDFs
  make fetch-wikipedia    - Fetch Wikipedia data
  make process-pdfs       - Process PDFs with OCR
  make generate-index     - Generate search index
  make fetch-all          - Run all data operations

Docker:
  make docker-build       - Build Docker images
  make docker-up          - Start containers
  make docker-down        - Stop containers
  make docker-shell       - Open shell in container

Development:
  make serve              - Start web server (port 8080)
  make format             - Format code with black
  make lint               - Lint code with flake8
  make test               - Run tests

Cleanup:
  make clean              - Clean temporary files
  make clean-data         - Clean processed data
  make clean-all          - Clean everything

Information:
  make help               - Show all commands
  make info               - Show project info
  make status             - Show system status

DOCKER COMMANDS
---------------

Build and run:
  docker-compose build
  docker-compose up -d app
  docker-compose exec app /bin/bash

Run specific services:
  docker-compose run --rm fetch-public-files
  docker-compose run --rm process-pdfs
  docker-compose run --rm generate-search-index

Stop and clean:
  docker-compose down
  docker-compose down -v  # Also remove volumes

PYTHON SCRIPTS
--------------

All scripts are in the scripts/ directory:

1. fetch-public-files.py
   - Fetches FBI Vault PDFs (22 files)
   - Downloads DOJ flight logs
   - Verifies file integrity with SHA-256

2. fetch-wikipedia-data.py
   - Fetches Wikipedia articles (15+)
   - Extracts dates, locations, characters
   - Generates profiles and timeline

3. process-pdfs.py
   - Extracts text from PDFs
   - Performs OCR on scanned documents
   - Extracts metadata

4. generate-search-index.py
   - Creates searchable index
   - Works with Lunr.js
   - Generates JSON index file

5. safe-source-expander.py
   - Monitors official sources
   - Creates GitHub issues with findings
   - Requires human approval

6. manage-volunteer-access.py
   - Manages volunteer permissions
   - Processes applications
   - Creates access controls
